# موقع تطبيقات ANAS GDXJ

موقع بسيط وسريع لعرض وتحميل تطبيقاتك الأندرويد.

## طريقة الرفع على GitHub Pages

1. ادخل على GitHub وسجل دخول
2. اضغط "New repository"
3. سمِّه مثلاً: `anas-gdxj-apps` (أو أي اسم تبيه)
4. ارفعه كـ Public
5. ارفع الملفات الثلاثة: `index.html` + `style.css` + `script.js`
6. ادخل على Settings → Pages
7. تحت Source اختر Branch: `main` و Folder: `/ (root)`
8. احفظ، وبعد دقيقة أو دقيقتين الموقع راح يكون جاهز على الرابط:
   `https://USERNAME.github.io/anas-gdxj-apps`

## كيف تعدل الموقع

### تغيير الصور
افتح `index.html` وابحث عن السطور اللي فيها:
```html
<img src="https://placehold.co/..." 
```
غيّر الرابط إلى رابط صورتك المباشرة (مثلاً من Imgur أو أي استضافة صور).

### تغيير روابط التحميل
ابحث عن:
```html
<a href="#" class="download-btn"
```
غيّر `#` إلى رابط ملف الـ APK (يفضل ترفعه كـ Release في نفس الريبو أو على Google Drive).

### تغيير النصوص
كل النصوص واضحة داخل `index.html`، عدّل اللي تبيه.

## ملاحظات مهمة

- لو حجم الـ APK كبير، ارفعه كـ Release في GitHub مش داخل الملفات العادية.
